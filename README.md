# 敷地・法規チェック

敷地と計画の数字から、建蔽率・容積率・絶対高さ・道路斜線・隣地斜線・北側斜線・防火・接道を判定するチェックシートです。計算式と条文を表示するので検算できます。

- 公開ページ: https://takeda-png.github.io/hoki-check/
- 1ファイル（`index.html`）で動きます。ビルド不要。
- 表示している案件はサンプル（架空）です。
- 資料（重説など）からAIで数字を読み取る機能は claude.ai 上でのみ動きます。このページでは手入力で使います。
- 天空率・日影の計算・高度地区の数値・自治体の条例は扱いません。結果は設計の検討用で、確認申請の代わりにはなりません。
